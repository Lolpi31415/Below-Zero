## BELOW ZERO
Below zero is a game that is about a miner that got trapped in a cave that he was exploring. He has to mine ores in order to buy a trampoline and BOUNCE BACK out of the cave. There is a deadly snake that chases him and the miner has to either doge it or remove it.

## Learning
Something that we as a group learned was grid algorithms for the snakes bot tracking as well as pygbag and pygame in order to make the game workable in the browser as well as making the project in the first place.

## Creators
This game was developed by Jonathan A, Declyn E, and Essa K. 

## Credits
Map was taken from Chrono Trigger's Magic Cave map right before entering Magus' castle. Ore textures were found for free online as well as the sprite and its animation. 
Game was thought of and designed by Jon. Essa worked on developing the grid algorithms, and Declyn was the main artist for the non premade assets.
Music was made by Jon as well, integrated into the game by Essa.

## Controls
Game is a simple WASD movement mechanics. Users must left click in order to damage the snake and right click to mine the ores.
